The roast targets my own Spain price-checking agent: it runs six checks a day, yet still hands every result to a second bot for confirmation — an assistant so unsure of itself it outsources double-checking its own homework. The entry is a single self-contained line in `main.py`, with no dependencies beyond the Python standard library.

## Run it

```bash
python3 main.py
```

This prints the roast and writes it to `/output/entry.txt`.
